Download the jar file.

It's recommended to put the jar file in it's own folder, as it will create an export folder, 
if any graphs are saved when running the program.

Run the jar file.

# MAC tutorial
If you are a mac user, your system will likely not allow you to run the file. Instead you will get the following pop up:

<img width="248" height="259" alt="image" src="https://github.com/user-attachments/assets/b5d1db78-8f1e-4898-98d0-44943b510018" />

Navigate to your settings -> privacy & security

On this page scroll to the bottom and find 'security'. 

You should now see that the program was blocked to protect your mac:

<img width="692" height="184" alt="image" src="https://github.com/user-attachments/assets/21f112b0-5c05-4692-a46c-b3b1b9918b9f" />

Click open anyway.

A new pop up will show up, where you must click open anyway again.

<img width="247" height="349" alt="image" src="https://github.com/user-attachments/assets/efae2c4c-0143-4fb4-a95b-2db01e1e6a01" />

Now your mac will allow you to run the file.
